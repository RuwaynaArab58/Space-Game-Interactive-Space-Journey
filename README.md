Space Game – Interactive Space Journey

Project Overview

Space Game is an interactive 2D game developed as a university project using C++ and OpenGL. The game takes the player on a space journey, starting from Earth and traveling through space toward the Moon.

The player controls a space journey while exploring different scenes and avoiding obstacles such as asteroids.

The project focuses on creating an interactive graphical experience using computer graphics concepts.

Game Features

- An introductory scene showing Earth.
- An astronaut and a spaceship launching into space.
- Animated stars, planets, and asteroids.
- Keyboard controls for player interaction.
- Collision detection between the spaceship and asteroids.
- A Game Over screen when the player hits an asteroid.
- A You Win screen when the player successfully reaches the Moon.

Technologies Used

- C++
- OpenGL
- GLUT
- Visual Studio

Technical Concepts Applied

Computer Graphics

Used OpenGL to draw and display 2D objects and create different game scenes.

Animation

Implemented movement and animation for different objects, including the spaceship and asteroids.

Keyboard Interaction

Used keyboard input to allow the player to interact with the game.

Collision Detection

Implemented collision detection to determine when the spaceship hits an asteroid.

Game States

Created different game states, including the introduction, gameplay, winning, and losing screens.

Learning Outcomes

Through this project, I gained practical experience in C++ programming, computer graphics, animation, keyboard interaction, and game development.
